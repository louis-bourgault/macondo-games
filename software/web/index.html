Ferretboard WASM

This is a WASM version of the games that will be running on my Ferretboard that I make, as a proof of concept and for development purposes. I will be adding more as I continue working on the project.

Information: github.com/louis-bourgault/macondo-games

Use WASD and arrow keys for d-pad buttons. Use J and K for A and B buttons, respectively. Use Enter for START and Shift for SELECT.

I am aware that this is possibly the most boring game that could possibly be made. It's a demo. I will improve it later, it's just a proof of concept that I can get it running through WASM.
