# Software

This is software to control the RP2040 console with a screen. However, I aim to have all internals abstracted away, such that any game can also be compiled with the target of my PC for debugging.

## AI Usage
Tools: Github Copilot in VS Code 
Used somewhat to help write implementations of the compilation target of WASM, since my interest lies more in the physical device and WASM compilation is mostly present for debugging purposes and initial proof of concept. I understand what everything does, and AI was never used on Agent mode to autonomously edit files, it was only used on ask mode so i had to write it into my code myself.
