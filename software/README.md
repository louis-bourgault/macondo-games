# Software

This is software to control the RP2040 console with a screen. However, I aim to have all internals abstracted away, such that any game can also be compiled with the target of my PC for debugging.

## AI Usage
Tools: Github Copilot in VS Code 
How: For the compilation target of my PC, the code is largely written by AI - this is because I want to focus on making the games work on my RP2040 device, with the PC compilation not the aim but rather a means to an end (helping me debug it, since PC drawing to windows is not something i am particularly interested in)
For the other code, I aim to write all my code. I keep the Github Copilot sidebar open to ask it questions and advice, but on "Ask" mode rather than "Agent" mode, meaning that it cannot change files and I need to do that manually (it is only there for advice.)
