## The files in here:

- casev2.f3d/.step - the case, on its own. does not include cad model of screen or pcb
- st7789_display.f3d/.step - model of the display that I use. Took me a decent amount of time to model, so i'm including it.
- fbv2_including_pcb_and_screen.f3z - an archive file including all the component parts. this uses multiple fusion files from seperate components, as well as the PCB, imported from Kicad. What all the screenshots are of, but not neccesary for the case design - hence no step files. Also, multi file exports get annoying from Fusion
- 3dp/ - the production STL files for the upper and lower sections of the case. Put these into your slicer.
